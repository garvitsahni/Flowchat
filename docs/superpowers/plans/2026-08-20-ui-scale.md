# UI Scale & Readability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bump the FloatChat frontend type scale one consistent notch and loosen the tightest paddings so it reads like a polished ops dashboard instead of a cramped terminal, without touching the palette or component logic.

**Architecture:** Pure presentation-layer change in 7 frontend files. Every edit is a class-string swap on existing elements — same tokens, same component boundaries, no new dependencies, no new files. Verification is the production build (`npm run build`) plus `grep` assertions on source and on the dev server's served CSS, since the repo has no unit-test framework.

**Tech Stack:** React + Vite + TypeScript, Tailwind v3.4 (JIT), inline SVG icons, existing `cn()` helper.

## Global Constraints

- No palette changes, no token renames, no Plotly/Leaflet swaps, no new features (spec "Non-goals").
- Keep the mono instrument-panel aesthetic: `font-mono` on meta labels and section titles stays.
- Token names (e.g. `text-bio-400`, `bg-abyss-800`) are unchanged — only the `text-[npx]`/`text-xs`/`text-sm`/`text-lg` size utilities and padding utilities change.
- Windows host: run commands from `C:\Users\Garvi\Desktop\Projects\FloatChat\frontend` via the `workdir` parameter; do not `cd`.
- Dev server Tailwind caveat (from prior work): Tailwind JIT reads source once per dev-server start, so a full dev-server restart is required before verifying served CSS; `npm run build` always compiles fresh.
- Footer hint line "enter to send · shift+enter for a new line" must be removed (only deletion in the plan).
- The `tracking-widest` section titles ("DEPTH PROFILE", "CONFIDENCE HIGH", "no data in scope", "insufficient data") are KEPT — only their size changes.

## File Structure

- `frontend/src/index.css` — base `body` font-size (15px → 16px)
- `frontend/src/App.tsx` — header title + header meta labels
- `frontend/src/components/ChatPanel.tsx` — empty state, suggestion chips, message cards, composer, language toggle, footer hint removal
- `frontend/src/components/VizPanel.tsx` — empty-state captions, refusal/insufficient-data cards
- `frontend/src/components/ConfidenceBadge.tsx` — low-confidence badge label
- `frontend/src/components/ExplainabilityDrawer.tsx` — toggle row + header row + SQL block
- `frontend/src/components/TrajectoryMap.tsx` — map overlay chip

Size ladder used everywhere (spec table):

| Old | New |
|---|---|
| `text-[10px]` (footer hint) | **removed** |
| `text-[11px]` | `text-xs` (12px) |
| `text-xs` (12px) | `text-[13px]` |
| `text-[13px]` (chips, errors) | `text-[14px]` |
| `text-[14px]` (messages, composer) | `text-[15px]` |
| `text-sm` 14px (empty-state heading) | `text-[15px]` |
| `text-lg` 18px (header h1) | `text-xl` 20px |
| body 15px | 16px |
